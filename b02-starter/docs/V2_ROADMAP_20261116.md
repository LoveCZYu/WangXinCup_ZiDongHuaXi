## 核心决策

下一轮主线是 **航迹历史条件下的可训练关联，配合可信状态更新**。保留点分类器作第一阶段证据源，升级“这个点属于哪条航迹”的能力。状态估计、门控、出生／确认／终止等模块分别对照，再组合胜出项。原论文依据和适用限制见 [研究笔记](V2_RESEARCH_20261116.md)。

## 第一轮：小范围但能回答关键问题

先在同一批 8 个内部校准文件上重新跑当前冻结 v1。新增记录：正确点是否进入候选、候选内是否分错、低可信更新后是否失稳、同一 ID 混入几条真值、首次起批／重新起批／失配删除分别损失多少。点命中、杂点、连续覆盖和原始统计都保留；真值只用于监督或诊断。

首轮限定四组，固定同一权重、点分数、数据、输出门限和其他常数：

1. 冻结 v1 对照。
2. 仅保护低可信匹配的完整运动更新：重点补上 position，避免把旧 velocity trust 实验再当新改进。
3. 仅改变可信命中累计／确认：把历史强证据与每次机械匹配分开。
4. 仅改变拒配 dummy 决策：避免为了完成匹配而接受不可信关联。具体规则在运行前固定。

这些组既测试假设，也同步收集真实轨迹前缀和候选边，供下一阶段训练。先不同时换滤波器、关联模型、门控和输出规则。建议首轮硬预算为 **30 CPU 分钟**，这是工作上限，不是实测耗时或效果承诺；不完整的实验不记作通过。

## 第二轮：新增真正需要训练的身份关联模型

给每条候选边输入截至上一圈的航迹历史，以及当前原始点。首个模型用小 MLP；若历史摘要不足，再比较短历史 GRU 或小型注意力，不直接照搬视觉检测器。

- **输入**：相对最后观测／预测的残差、历史速度方向与当前位移一致性、候选拥挤程度、当前点分数、Amp/SNR 及变化、相对时间间隔、命中／失配掩码；有协方差后加白化残差。
- **监督**：同一目标边、不同目标边、本圈无匹配。场景内真值 ID 只用于生成标签，不能作输入或跨文件身份类别；不使用 PntID、绝对时间或文件名充当身份捷径。
- **关键训练样本**：交叉／贴近目标中的另一条真航迹、两条旧轨迹竞争同一点、重复候选、断续后重现、门内高幅度杂点。保留随机负例，但不能让容易负例淹没难例。
- **训练分布**：先干净真值前缀，再加入跟踪器自身的因果回放前缀；历史污染按过去信息标记，不能用当前正确答案重新定义过去身份。未知标签点不强当杂波。
- **分配**：每条航迹有未匹配选项，当前点也可未分配；一对一约束继续由稀疏分配器保证。保持候选集和求解器不变，先判断学习项本身是否有用。
- **必要检查**：候选召回是前置条件。真匹配已被固定门挡掉时，学习器无法恢复它；单独报告这类失败，不能伪装为模型拒配成功。

思路参考 [MOTIP 原文](https://arxiv.org/html/2403.16848v2) 的历史条件身份关联；只迁移问题建模，雷达特征、训练样本与协议适配由本队实现，不继承其视觉数据成绩。

首个训练试验建议最多 **1–2 GPU 小时、另限 1 CPU 小时预处理**，先用小规模样本判断方向。先跑吞吐试验再确定 batch 与更新数；没有效果信号就停止扩训。之后增加训练场景及时间片段覆盖，保持原 8 个校准文件、30 个开发文件不进训练；原训练池扣除校准后最多 132 个场景可用，但不要求第一轮全部展开。

## 第三轮：按残差证据升级运动估计与航迹管理

将现有固定归一化距离门与 EMA 运动，分别对照为“归一化坐标中的局部 CV Kalman＋训练残差估计的协方差门控”。文档 Time 单位是 ms，但仍先核对相对时间和扫描节奏是否一致；角度／距离的物理标定未确认前，不强行转成真实米制三维或假设方位首尾相接。

同时检查候选召回、竞争密度和 ID 混合；放大不确定度不应自动获得更低匹配代价。航迹存在证据、状态更新可信度、当前点是否输出分别记录。只有单模型残差证实平稳／机动模式有差异，再试两模型 IMM；只有单假设残余歧义足够多，再试严格受限的多假设。它们不是首轮一起堆叠的必需模块。

依据为 [PMBM 原始推导与实现](https://arxiv.org/html/1703.04264v3) 的状态／存在／关联分离，以及 [IMM 原始机构记录](https://research.tudelft.nl/en/publications/an-efficient-filter-for-abruptly-changing-systems/)。这些方法也不能直接提供 B02 得分保证。

## 采用与放弃条件

先看身份质量和连续覆盖，再检查代价是否来自明显漏点、杂点或起批退化。建议预注册一个阶段目标，例如“校准集变号减少 25%、连续子分提高 3 分、点命中最多损失 0.3 个百分点、杂点最多增加 5%”；这些数字是可讨论的工程门槛，不是预计收益，也不是比赛额外规则。最终完整指标和局部失败案例必须一起呈现。

学习候选至少两种子复查；不在开发集挑最好种子。校准选定完整配置后，冻结候选再跑 30 文件开发回归，不边看边继续改。公开 A 榜五包只用于完整版本的同条件验证和官网打分；原 train_003 不重新进入训练，剩余 29 个 `holdout_unseen` 场景继续不动。封存验证如未来需要，应另按明确阶段约定执行，本轮不触碰。

最终输出只能选择当前原始点并附持续正整数 ID；预测点不输出、旧结果不回填、未来圈不参加推理。重新验证多包状态重置、同一前缀结果一致、追加未来输入不改既有输出，以及全量推理显存与时限。
