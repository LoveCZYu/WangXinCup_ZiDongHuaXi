## 先做什么

1. 固定三个成熟对照：宽方案、单记忆检查、接续评分加记忆检查。固定权重、代码摘要、门槛、主比较和采用条件，暂不增加校准阈值组合。
2. 审核所有模型层、历史实验、后羿分支的数据使用记录，包括文件版本、重复／近重复或可能同源场景。划分元数据中有 52 文件不在当前 fit64 和已列评估角色内；这个差集只代表候选池，尚不证明它们从未用于任何模型或调试。
3. 从使用审核合格的候选池中，按查看结果前固定的规则保留一批新工作验证场景。现有 29 个正式封存场景不读取；如没有合格新场景，不把已看过的数据改称独立验证。
4. 成熟候选做一次预先规定的配对验证。主要检查混轨改善是否保留、总分／命中／起批／连续跟踪是否实质性回退，同时报告逐场景差异和不确定性。支持、证据不足、反证三种结论分开；不只选最好均值。一旦看结果并用于选型，记录它已经成为验证数据，不能再次宣称盲测。

## 同时做的只读诊断

在既有开发／校准场景上，对当前候选重新做错误归因和真值辅助反事实：

- 固定选出的点，诊断理想身份归属能修复多少损失；遵守同圈输出唯一性等约束，记录无法修复的冲突。
- 限制在当前真实候选内，诊断理想选择能修复多少损失，再与放宽候选的诊断比较。
- 检查去杂／漏点、首次起批、已有 ID 中途串轨、旧轨恢复、可信记忆污染各自的贡献。
- 增加输出 ID 纯度、较严格轨迹归属等影子诊断；将它们与现有估分分开，不冒充未公开的官方评分实现。

真值辅助诊断可使用未来信息，只用于定位瓶颈。其数值不是可部署模型成绩，也不直接承诺可实现上限。

## 根据证据选路线

| 观察 | 优先方向 |
| --- | --- |
| 当前收益在新场景明显回退 | 审核数据分布、标签和选型过程；停止围绕旧八文件堆规则 |
| 正确点常在候选外 | 改运动预测、不确定性和候选构造；仅改评分网络无法补回不可见候选 |
| 候选中常有正确点，但排序／拒绝错误 | 针对实际运行中的困难争抢采样，训练关联与拒绝，而非盲目加训练步数 |
| 已发布 ID 中途串轨仍占主要损失 | 联合比较现有 ID、失配 ID、候选点与不匹配项，处理身份竞争与记忆污染 |
| 现有候选／状态结构即使理想选择也限制很大 | 给不同结构的关联路线独立预算，先验证身份判别能力，再验证接入整场效果 |

保留一条稳定工程线和一个结构性对照。新结构按中间证据分阶段判断，不要求首轮就超过完整旧系统；也不以“再多训一点”无限延期。每两轮关键实验做一次路线复盘。

## 后续每次实验的最小记录

运行前记录：问题、假设、干预、对照、数据角色、预算、主要判据、会否定假设的结果及停止条件。多个改动分开比较；因资源或诊断追加的对照标明追加理由。

运行后记录：全部分项、身份行为、逐场景退化、种子差异、失败结果和角色变更。明确区分事实、对照支持的机制解释、尚待验证的推测。

不得把一次上涨写成通向满分的证明，不反向调整本地公式拟合官网总分，不按校准结果挑种子。成熟候选通过验证后，再准备正式五包复现与官网外部检验；不对每次小改动反复试榜。
