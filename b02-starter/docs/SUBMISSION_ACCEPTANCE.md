## 新版环境适配

官方协议、EXE、源码和 `train_005` 与旧版相同。主要变化是 ZIP 少一层目录，以及 Dockerfile 新增 i386／Wine32。准备工具已兼容两种目录，包内附官方 Apache-2.0 许可原文。

添加 Wine32 后，Debian 默认进入 32 位加载器，在当前容器出现 `wineboot: socket Function not implemented`。最小对照在默认方式失败，显式 Wine64 后通过；镜像通过专用脚本固定 64 位加载器，与官方 AMD64 EXE 匹配，仍保留 Wine32。沿用 PTY／有效 UTF-8 locale 适配。官方 EXE 与四个交互源码原样保留。

本机初始化日志仍有 32 位辅助进程的非致命兼容提示；初始化和实际官方服务均成功，完整运行由退出码、逐圈记录与航迹共同验证。不通过屏蔽日志或放宽安全设置冒充成功。
