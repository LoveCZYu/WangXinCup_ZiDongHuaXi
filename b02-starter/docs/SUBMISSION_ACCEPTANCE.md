## 启动兼容修复

原官方 EXE 在 Wine 下将输出直接重定向到文件时，内置 Python 报 `init_sys_streams / WinError 6`。最小对照排除了模型和输入数据：只改 stdin 无效，输出接 PTY 后启动成功；使用镜像中有效的 `C.UTF-8` 后中文也恢复。回归测试先在原启动方式失败，适配后通过。

`src/launch_server.py` 仅在命令层增加系统 `script` 伪终端和 UTF-8 locale。官方 EXE 及四个收发源码文件保持逐字节原样；算法、权重、门限和协议不变。最终双跑使用的是修复后程序包。
