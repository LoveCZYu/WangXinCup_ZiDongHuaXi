# B02 v2：在线身份关联研究与可执行实验顺序

日期：2026-11-16。本文只做一手资料研究与方案建议；没有改算法、训练、调用 GPU 或运行云端实验。主线程复核后的执行顺序和预算见 [v2 路线](V2_ROADMAP_20261116.md)。

## 结论与证据边界

下一轮应学习“当前点属于哪条已有航迹”，并验证内部状态是否被低可信匹配带偏。单纯扩大当前点分类器，无法直接解决两个高分目标点之间的身份交换。

依据是已有 [DIAGNOSIS.md](../experiments/association/DIAGNOSIS.md)：旧 8000 步控制组在 8 个内部校准文件的固定对照中，本地分数约 79.98；只清除输出杂点约增加 0.61，而只用真值重写已有输出身份约增加 12.87。94.53% 的变号发生时旧 ID 仍存在，79.76% 发生在相邻真值观测之间，简单延长 missed 不是首选。这里的真值干预不可部署，也不是可达上界，更不是当前 v1 的官方预测。官方 A 榜 v1 成绩为用户提供的 75.24；本文没有复现官方评分器，不把内部得分与官方成绩直接换算，也不承诺任何目标分数。

在已有代价 `d(track, point) + 0.5 * (1 - pointness(point))` 中，对同一组点交换两条航迹的配对，点分数项之和不变。需要一个真正依赖航迹历史的交互项。当前 `b02/algorithm.py` 与 `experiments/association/interventions.py` 还显示：匹配先更新位置、命中和候选状态，输出门随后筛点；只减小最终输出杂点，不能保证内部状态干净。这是实验假设的代码依据，具体收益仍待对照。

主线程代码复核还确认：当前点网络只用 xyz 与局部几何，不含 Amp/SNR/Time；Amp 仅用于出生排序，SNR 尚未使用。已有 combined 只抑制低分匹配的速度增量，位置与命中仍直接更新。训练监督为 32 场景 × 8 片段 × 8 圈，即 2048 帧；4000→8000 步没有增加监督帧。因此“加入航迹历史和身份监督”与“在相同点分类数据上延训”是不同实验。

## 三个方法锚点

| 一手方法 | 文献实际提供什么 | B02 可迁移的部分 | 不能直接搬用的部分 |
| --- | --- | --- | --- |
| MOTIP，Gao、Qi、Wang，CVPR 2025，§3.1–3.4 | 给历史轨迹附上上下文 ID，预测当前检测的 ID；关联作为可训练任务，ID 不是跨场景固定类别 | 使用每条航迹自己的历史，输出当前候选关联分数；训练时随机重排局部身份，避免学习数字 ID | 图像检测器和视觉对象嵌入不适用于雷达点；论文成绩不构成 B02 收益证据；没有理由照搬完整 Transformer |
| PMBM，García-Fernández 等，2018，§II、III、V | 以当前及过去测量进行递归滤波；区分状态密度和存在概率；维护互斥关联假设，使用门控、k-best 分配和裁剪 | 协方差描述预测不确定度；将“漏检”作为显式选项；存在证据与位置更新分开；限制歧义分量的假设数 | 原模型假设点目标每圈至多一个测量、Poisson 杂波等，必须先检查 B02 标注是否符合；其状态均值输出与 B02 原始点输出协议不同 |
| Blom，1984，原始 IMM | 针对 Markov 切换动态系统，使用相互作用的多个运动模型控制递归计算复杂度 | 在单模型滤波已校准后，用两个过程噪声水平的 CV 模型表达平稳/机动状态，再考虑更复杂模型 | 未知归一化角度/距离标定时，不能直接套物理转弯半径、m/s、角速度常数；IMM 不能消除身份关联错误 |

以上事实分别见 [MOTIP 作者论文](https://arxiv.org/html/2403.16848v2)、[作者代码仓库](https://github.com/MCG-NJU/MOTIP)、[PMBM 作者论文](https://arxiv.org/html/1703.04264v3)、[Blom 原始 IMM 的作者机构记录](https://research.tudelft.nl/en/publications/an-efficient-filter-for-abruptly-changing-systems/)。下面是针对 B02 的工程推演，不是这些论文已验证的结论。

## 首选结构：历史条件下的稀疏关联

保留现有点分类器和原始点输出接口，新增一个小型边打分器。每条边由“截至 t−1 的航迹历史 + 当前 t 的候选点”组成；先用 MLP 做可解释基线，有证据后再比较 GRU 或小型历史注意力。不要一开始构造全场景、全历史的稠密图。

建议的航迹输入为最近 K 个真实匹配点、相邻扫描间隔、漏检掩码、归一化位移/速度差、已有点分数、Amp/SNR 变化、航迹年龄和可信命中证据。候选输入含相对最后观测和相对预测的残差、残差方向与历史方向的一致性、候选点分数、Amp/SNR、当前局部拥挤程度；有协方差后增加白化残差。Amp/SNR 只是待学习线索，不能当作稳定的外观身份签名。

第一版仍用当前门控生成稀疏边，单独统计“正确当前点是否进入旧航迹候选集”。该召回率限制任何边打分器的收益。匹配器使用航迹专属的拒配 dummy；当前点允许不匹配，出生与杂波需要区别处理。不要将所有点强制分给某条旧轨迹。打分器输出经过校准的关联代价，再做当前圈一对一分配；同时保留简单距离代价对照，避免把优化器变化误认为学习收益。

这里借鉴的是 MOTIP 的历史条件身份思想。B02 没有图像、bbox、ReID 或 Doppler，不能从视觉模型推断存在这些信息。历史只能来自已接收扫描；未来圈、双向编码、轨迹平滑和整段全局重标都不能进入在线推理。滤波预测只用于候选和代价，最终必须复制当前输入原始点字段并附正整数持久 ID，不能输出预测点或修正过的坐标。

## 训练标签与难负样本

1. **按文件划分训练/开发。** 同一目标的相邻圈不能跨分区；特征归一化、噪声估计和阈值校准只拟合训练分区。A 榜公开的 `train001–005` 只作为已知公开检查集记录；29 个独立封存文件继续不看，候选冻结后再按预先约定做一次验证，不能回流调参。本文没有读取这些封存文件。
2. **正例是身份边，不是目标点。** 训练时用标注 ID 判断历史航迹与当前点是否同一目标；模型输入中删除所有真值 ID。使用局部槽位或随机重排的上下文身份，不能把不同文件中相同数字 ID 当同一物体。
3. **先干净前缀，再加入真实回放前缀。** 干净历史可稳定学习运动，但必须加入模型自身因果回放产生的漏检、错接和重复候选，防止只学会理想航迹。历史参考身份只能由 t−1 及以前的标注确定；混合身份前缀标记污染/拒配样本，不能根据当前正确答案重新定义历史身份。属性未确定的点使用显式忽略掩码，不强行视作杂点。
4. **关键负例是其他真目标。** 优先采样交叉/近邻中高点分数的另一目标、同一当前点面对竞争旧轨迹、重复候选、漏若干圈后的陈旧轨迹，以及门内高 Amp/SNR 杂点。大量随机远点过于容易，不能占满训练批次；保留一定随机负例帮助校准，并记录采样权重。
5. **拒配要有监督。** 对每条历史轨迹，在候选点加 miss 的集合上训练分类；正确点不在候选集时单独记门控失败，不能把它伪装成真正漏检而掩盖候选召回问题。对未分配当前点再学习新目标/杂波，避免把身份关联和点分类混为一项。
6. **先检查最小反例。** 两条轨迹、两个都高分的当前点，交换配对应改变学习代价总和；用同分点与历史置换检查模型确实使用了轨迹身份信息。记录边分类质量后，仍以完整在线回放的变号、混合 ID、漏点和杂点判断有效性。

## 不确定度、存在证据与状态更新

先做归一化坐标中的 CV Kalman 基线，用训练前缀残差估计每轴 R/Q，必要时按历史可信度和漏检间隔分组。这里 CV 仅是该坐标表示下的局部统计近似，不声称真实物理匀速。赛题文档已给出 Time 单位为 ms；仍需核对点时间差的单调性和扫描节奏，使用相对时间间隔，不使用绝对时间作为身份捷径，也不做未知角度标定的三角变换。

候选残差 `e = z - H x_pred`，创新协方差 `S = H P_pred H^T + R`；可比较 `e^T S^-1 e` 门控和包含 `log det S` 的高斯负对数似然代价。只用 Mahalanobis 项会偏爱过度不确定的轨迹；协方差必须设上下限并检查数值稳定。理论卡方阈值只在相应误差模型成立时有覆盖解释，实际先用独立开发残差检查覆盖率。门变大可能减少门外漏点，也可能增加身份竞争，必须一起观察。

将三件事拆开记录：用于运动更新的测量可信度、航迹存在/身份可信度、当前点是否输出。低可信匹配可进入待定证据池或减弱位置与速度更新，但不能直接累计为强确认；不能只缩小 velocity gain 而继续硬覆盖 position。若没有校准的检出率、杂波密度、出生率，先称“存在证据分数”，不要把 heuristic sigmoid 包装为 PMBM 后验概率。已存在与当前可观测也不同：漏检时可以保留内部航迹，仍不得输出不存在的当前原始点。

单模型残差显示明确的机动/平稳差异后，再对照两模型 IMM（相同 CV 状态、不同 Q）；先避免引入未知物理标定的恒转弯模型。若错误主要发生在清晰高分真目标之间，IMM 只能是辅助，不能替代历史条件关联。

## 有限多假设的严格因果边界

PMBM 的递归假设管理提示可以保留歧义，但 B02 的即时、不可修改输出约束比常见轨迹估计更严格。只在当前候选二部图的歧义连通分量内尝试少量 k-best 分配，限制分量大小、每轨候选数、beam 数和历史长度；超限确定性退回单假设。数值上先试很小的 2/4 分支，属于待验证的工程预算，不是论文推荐参数。

每个分支只能使用截至当前圈的信息。当前输出必须立即选择并固定；不允许等未来圈后补发旧点、重写旧 ID、合并/重命名已经输出的 ID。保留分支必须与已提交的可见身份映射一致，因此分支主要帮助未输出候选、隐状态和运动模式的不确定度；若分支对当前已输出点的身份相互冲突，提交后需删除不兼容分支。未来测量不能追溯修正本圈已犯的身份错误。这会明显削弱传统延迟决策 MHT 的优势，故优先级低于单圈历史条件关联。

不要直接采用离线图求解的整段全局优势。例如 [Brasó、Leal-Taixé 的 Neural Solver 原文](https://openaccess.thecvf.com/content_CVPR_2020/html/Braso_Learning_a_Neural_Solver_for_Multiple_Object_Tracking_CVPR_2020_paper.html) 以检测图上的全局消息传递求关联；若图或消息含未来检测，B02 不可用。只截取过去前缀并保证输出不可回改，是新的受限模型，不能沿用原论文效果声称。

## 实验顺序与通过条件

首轮限定为 **4 组、不训练**：固定当前 v1 基线；仅改变低可信匹配的完整运动更新；仅改变可信命中/确认累计；仅改变拒配 dummy 的决策。各改动分别对照基线，不先组合，不批量搜索门限。与这些回放同步收集 pair 样本、候选召回及污染日志，再进入历史关联打分器训练。如果 v1 基线已包含 velocity trust，完整运动更新组只补上仍缺少保护的位置更新，避免重复已有对照。具体 dummy 规则在实验清单里预先固定；不通过调低输出量制造“纯度提高”。

下表是后续阶段顺序，不是首轮同时叠加的算法清单。

| 顺序 | 单独改变的内容 | 要回答的问题 |
| --- | --- | --- |
| 0 | 固定 v1 数据划分、种子、权重与回放诊断；加候选召回/状态污染日志 | 对照是否可重复，旧轨正确候选究竟漏在哪层？ |
| 1 | 低可信匹配的完整运动/命中更新隔离；保持关联代价与输出规则固定 | 隐藏的杂点更新是否实际造成后续门外漏点/串轨？ |
| 2 | 小型历史边打分器；保持候选集和匹配器固定 | 同一组高分真点之间能否减少变号与混合身份？ |
| 3 | 单模型协方差门控/代价，再单独加入存在证据 | 是否改善门外漏点，且不会通过放宽门增加串轨？ |
| 4 | 有残差证据才加两模型 IMM | 机动子集收益是否超过复杂度与误差校准成本？ |
| 5 | 最后才试与已提交输出兼容的有限分支 | 剩余歧义是否足够多，值得付出运行与维护成本？ |

这是消融顺序；步骤 1–3 的胜出单项才组合，不同时替换全部部件。先在既定内部校准集比较，再在允许的完整开发范围确认；封存集只在冻结候选后验收。报告逐文件分布、连续子分、变号数、混合 ID、点命中与杂点，以及总耗时/峰值内存；总分上升但混合身份恶化也必须显示。无需追求固定论文架构或指定分数。

在线状态只保存受限历史、稀疏边和受限假设。用真实最大点数、最大活跃轨迹数验收时间和峰值内存，确认离线推理不超过 24 GB；小参数量本身不能证明内存合格。所有版本都要验证：输出点确属当前输入、原字段未改、当前点不重复归属、ID 为持久正整数、重复前缀输入输出一致，并且向输入后方追加未来圈不会改变既有前缀输出。
