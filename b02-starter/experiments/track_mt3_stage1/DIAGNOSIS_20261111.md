# Track-MT3 零航迹诊断

本报告针对 CNSF 作者仓库的 Track-MT3 对照实现，固定提交 `22c3a19c15df6c560eaadc74462b9b632ede2602`。不涉及 B02 数据，不宣称发现或修复原论文算法缺陷。

## 已定位的直接原因

第 401 步检查点在三个固定种子的 100 帧模拟序列上，未经筛选的最大置信度仅 0.40848，低于新航迹起批阈值 0.75。由于从未起批，也没有旧航迹可传播。保留一个完整历史窗口仍然复现该症状。

复现命令（在 CNSF 源码根目录，使用云端虚拟环境）：

```bash
python /root/shared-nvme/b02/scripts/repro_empty.py --frames 21 --start 20
```

实测输出：`frames_evaluated=1, outputs=0, checkpoint_step=401`，随后按预期触发 `AssertionError: REPRODUCED: zero tracks emitted by saved model`。这是一条症状断言，不能作为完整效果验收。

## 阈值并非单独的修复办法

每组从空航迹状态重新运行；三个固定模拟种子 20261111–20261113，每个 100 帧，汇总评分帧为 20–99，共 240 帧。原模型权重不变。

| 起批阈值 / 维持阈值 | 每帧平均输出 | 平均 GOSPA | 说明 |
| --- | ---: | ---: | --- |
| 0.75 / 0.90 | 0 | 4.646 | 所有候选被过滤 |
| 0.50 / 0.90 | 0 | 4.646 | 仍达不到阈值 |
| 0.25 / 0.90 | 16 | 17.896 | 每帧输出达到模型上限，误报严重 |
| 0.25 / 0.50 | 16 | 17.896 | 继续放宽维持阈值没有改善 |

GOSPA 使用仓库默认 cutoff=2、order=1、alpha=2，越低越好。在这个定义下，空预测器的每帧代价等于真目标数；此处每帧平均 4.646 个目标。该指标不是 B02 官网分数。阈值试验只是诊断，不将这些序列用于正式模型的阈值选择。

## 模型表现与实现检查

- 检查点中的模型、模拟器、损失配置与阶段 1 推理加载的上游配置一致。
- 固定窗口上 `forward_window` 与单条批量 `forward_windows` 的位置和 logits 最大差均为 0。
- 从窗口中移除真值位置、真值 ID 和量测标签后，位置和 logits 最大差仍为 0；该次推理没有依赖这些标签。
- 将同一窗口的所有量测坐标置零，预测位置平均变化仅约 0.059（原二维场景单位）；这支持模型对输入的定位响应仍弱，但仅是一个窗口的扰动证据，不是普遍的灵敏度结论。

在相邻两个窗口的探针中，第一个窗口位置匹配成功的 5 个候选，平均置信度 0.3853；其余 11 个候选平均 0.3830，基本没有分离。使用真值辅助把匹配候选传到下一窗口后，5 个旧航迹平均置信度升至 0.9971，而一个新目标对应的检测查询概率只有约 0.00794。这里“匹配成功”只是训练匹配规则分配了目标，并不保证预测位置足够准确。

这支持一个具体判断：该早期检查点对“旧航迹查询”高度自信，但新目标辨别尚未学好。训练时 teacher forcing 会利用真值匹配保留低置信候选，正常推理没有这一帮助。这个机制存在不代表 teacher forcing 本身是错误；它是否是当前学习不良的主要原因需要对照验证。

## 固定小样本与随机续训

两组都独立从第 401 步检查点开始，保留网络、损失及 0.75/0.90 阈值。

固定小样本组：用种子 90119 生成两个片段、每片段两个窗口，重复训练 300 步。只在这同一组窗口上测量，平均真目标数 4。平均输出由 0 变为 4，全部真目标都有 cutoff=2 内的配对，平均 GOSPA 从 4.000 降至 0.412。这证明训练链路具有拟合该样本的能力，不能证明泛化，也不能完全排除更隐蔽的实现问题。

随机续训组：沿用短训练配置，额外训练 2000 步，在固定独立种子 20261111 的序列上检查。以下只评分帧 20–99，每帧平均真目标数 4.6375；没有基于这些检查点做正式模型选择。

| 总更新步数 | 每帧平均输出 | 平均 GOSPA |
| ---: | ---: | ---: |
| 401 | 0 | 4.638 |
| 901 | 7 | 11.038 |
| 1401 | 3 | 6.699 |
| 1901 | 0 | 4.638 |
| 2401 | 8 | 12.418 |

因此零输出的症状可以在继续训练后消失，但泛化效果没有随之变好。固定片段能学会、随机序列仍表现不良，不能仅凭损失下降或非空输出宣布修复。

## 真值辅助传播单变量对照

另从第 401 步检查点出发，只将 teacher forcing 的起止概率设为 0，保持模型、损失、数据生成序列、批量、片段长度、学习率和阈值不变，额外训练 500 步。与原配置从第 401 到 901 步的前 500 步作等预算比较：

| 单序列、总步数 901 | 每帧平均输出 | 平均 GOSPA |
| --- | ---: | ---: |
| 原 teacher forcing 退火 | 7 | 11.038 |
| teacher forcing = 0 | 0 | 4.638 |

关闭辅助后，最大候选概率为 0.74881，仍未超过 0.75；虽然置信度分布有所变化，不能视为学会了跟踪。不能将该结果解释为“关闭 teacher forcing 就解决了问题”，也不能仅由这两组小实验断言 teacher forcing 是深层根因。

最终对三个固定独立序列复查，每组均评分 240 帧：

| 检查点 / 推理阈值（起批、维持） | 每帧平均输出 | 平均 GOSPA |
| --- | ---: | ---: |
| 原第 401 步 / 0.75、0.90 | 0 | 4.646 |
| 固定样本训练至 701 步 / 0.75、0.90 | 4.333 | 8.860 |
| 随机续训至 2401 步 / 0.75、0.90 | 7 | 11.259 |
| 关闭辅助训练至 901 步 / 0.75、0.90 | 0 | 4.646 |
| 关闭辅助训练至 901 步 / 0.50、0.90 | 1.458 | 5.640 |
| 关闭辅助训练至 901 步 / 0.25、0.90 | 6.883 | 10.259 |

同一固定样本上的成功没有迁移到独立序列。所有这些诊断变体在所测独立序列上的 GOSPA 都没有优于空预测器，因此本轮没有可推广的“修复模型”。阈值只用于诊断，不据此选择最终阈值或报告正式测试成绩。

## 结论与下一步

**已确认**：原模型有候选，空输出发生在置信度阈值筛选；在固定探针中候选区分能力弱，旧航迹查询高度自信；固定样本能拟合，随机短训练的泛化未达标。已排除本次窗口中的配置错配、单窗口/批量路径不一致和真值标签参与推理这些解释。

**尚未证明**：是有效训练量、关闭课程学习、缩短片段、早期真值辅助依赖或实现偏差中的哪一项主导了泛化失败。小样本成功不能证明全实现无误；额外 2000 步失败也不能证明完整论文配方无效。本轮是诊断完成，不是效果问题已经修复。

下一步建议从新初始化做受控训练配方实验：先恢复上游课程学习与片段长度，只因显存调整批量；另保留短训练配置作为对照。按处理的片段/监督窗口数量记录预算，不能只比较 update 数。每个检查点必须在独立固定验证集上报告 GOSPA 分解、候选区分与自主航迹结果，再决定是否值得扩展训练。不要直接投入完整 40000 步，也不要直接把当前权重当作 B02 预训练模型。

本轮新增训练为固定样本 300 步、原配置随机 2000 步、无真值辅助随机 500 步；所有任务已正常退出，没有改动上游模型源码，没有替换原基线或推送 GitHub。
