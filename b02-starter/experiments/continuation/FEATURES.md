# 接续模型输入与监督

输入固定为 227 维。每个候选对应一个旧 ID 和准备输出的当前新轨；数值 ID 仅用于维护关系，不进入向量。

| 范围 | 内容 |
| --- | --- |
| 0–92 | 旧轨与当前原始点的 93 维同目标证据，距离按原始运动半径归一化 |
| 93–185 | 新轨与当前点的同构证据，包括新轨当前运动与历史上下文 |
| 186–194 | 新轨前两次观测与当前点，相对旧轨预测的三维残差，共九维 |
| 195–197 | 三次观测相对当前扫描的时间差 |
| 198–200 | 三次观测的冻结点分类分数 |
| 201–206 | 三次观测的 Amp／SNR 与旧轨历史均值的差 |
| 207–209 | 新轨三次观测拟合速度与旧轨速度的差 |
| 210–213 | 平均、当前、最大运动误差，以及速度差平方 |
| 214–215 | 原有同目标评分器在当前归一化与原始归一化下的分数 |
| 216–223 | 旧轨匹配间隔、输出间隔，新轨年龄，旧轨输出量及比例、退役标记、短旧轨标记、可靠记忆数量 |
| 224–226 | 同一新轨的候选数量、与其他旧轨的分差、同一旧轨与其他新轨的分差 |

93 维同目标证据的既有定义见 `experiments/id_recovery/affinity.py`。输入包含相对几何和信号统计，不包含绝对时间、点编号、真值编号或当前标签。

拟合数据来自冻结宽容差方案在 fit64 上的完整因果回放。外部采集器用当前已知点标签和旧 ID **此前**的已知输出标签生成监督；这些标签不传给跟踪器。旧 ID 历史全部为 -1 时掩码，不强行作为负例。旧 ID 的已知历史主身份占比至少 80%，且与当前正真值身份一致时为正例；已知杂点与身份不纯的接续为负例。

同一新轨的最多 12 个旧 ID 一起训练，超出时按冻结规则证据选前 12 个。二元判别损失与包含“保持新 ID”选项的组内排序损失共同训练。负例增加损失权重；多个合适旧 ID 的排序监督按此前同身份支持量加权。模型为 227→64→32→1，含少量 dropout。

从既有 fit64 中按 `fit64[::4]` 取 16 文件作为**接续头的拟合池内验证**，其余 48 文件训练。它们不是整套系统从未见过的数据；底层关联权重曾用 fit64 训练。接续头检查点以这 16 文件的目标函数选定，输出门槛也只在这些文件选择。保留的 `confirmation16`、开发 30 文件和封存测试集不用于本轮。

验证门槛考察组内胜者的精度和召回率。若目标精度下不足 20 个验证接续，则返回几乎全拒绝的保守门槛并明确标记不可行，避免将无依据的高精度宣称带入校准。校准回放才检验递归使用模型后的完整跟踪效果。
