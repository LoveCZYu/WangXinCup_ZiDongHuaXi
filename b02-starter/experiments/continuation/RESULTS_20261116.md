# 接续判别、运动门与长期记忆：阶段结果

本轮固定八文件校准候选为 `fusion_memory-20261116`，零碎度 70.0639，连续跟踪 86.5777，本地总分 85.2847。对照分别为 69.8870、86.5341、85.2438。达到校准零碎度 70 的阶段目标，但新增改善幅度有限，且尚未做独立验证，保留 v2 实验名，不改官网 v1 提交。

## 范围与固定项

完整回放 train_032、033、050、051、085、144、145、178；宽、窄两个影子组逐文件复现旧统计。点分类器、底层长期记忆关联权重和输出门槛固定。没有读取封存测试、确认 16 文件或开发 30 文件。所有训练监督仅在外部采集器产生，跟踪器输入没有真值。

## 四格对照

准入轴同时控制候选进入范围与三观测运动资格；评分轴控制距离特征归一化与距离排序惩罚。窄窄为 65.7144，只扩大准入为 66.4416，只放宽评分为 65.8679，宽宽为 69.8870。两者明显相互作用，不能把旧增益全归因于候选数增加，也不能只放宽评分后声称解决了漏候选。

## 两种子接续头

从冻结宽方案的 fit64 因果回放采集 2944 个候选组，包含 2146 个正候选和 1581 个负候选。48 文件训练，16 文件仅作接续头的拟合池内验证；这些文件曾用于底层关联模型训练，不能称为全系统未见验证。该 16 文件与保留的 `confirmation16` 不同。

输入为 227 维旧轨、新轨、三次观测及竞争证据，定义见 `FEATURES.md`。每个种子实际训练至 1600 步，检查点取验证目标最小值，未用校准得分选步数。较长训练的验证目标回升，因此不默认最后一步最好。

- 种子 20261116：选中 200 步；独立头门槛 0.99，保守门槛 0.99。
- 种子 20261117：选中 200 步；独立头门槛 0.999999，保守门槛 0.999999。

高精度直接替代头拒绝太多正确接续，两种子均未通过整体保护，完整失败结果保留。门槛选择不可行时使用接近全拒绝门槛，并明确记录不可行，而不宣称达成精度。

随后增加有限评分纠偏对照，不追加 GPU 训练。只在同一拟合池内验证比较 5 个融合系数与 4 个门槛，以“正确接续－5×错误接续”为代理，要求代理精度与收益均不低于冻结规则；这些是代理目标，最终仍用校准完整跟踪指标检查。

- 种子 20261116：评分融合系数 1.0，门槛 0.8；拟合池内验证代理收益 182→312。
- 种子 20261117：评分融合系数 1.0，门槛 0.8；拟合池内验证代理收益 182→282。

两种子实际都选择系数 1，即采用新头分数，同时保留原有运动资格和距离排序惩罚。因而它的效果也涉及门槛与排序配套，不能将其解释为“融合系数越大越好”。两种子通过整体指标保护且降低混轨代价后，才按预定条件在默认种子 20261116 上检查记忆组合，没有按校准挑更好的种子。

## 已有 ID 的长期记忆更新

单独检查此前至少输出三次、已有至少四条可靠记忆的 ID。在原有可靠性筛选通过后，再用既有同目标评分器检查该匹配；分数低于 .90 时暂缓写入长期记忆。该步骤不直接过滤当圈输出，也不改短期物理状态更新，但会影响后续关联。它只是中途串轨的一项传播控制，并未实现所有已发布 ID 的全局重新分配。

当前阶段停止追加门槛组合。自适应运动门与更大范围的联合匹配尚未实施：下一步需要针对已有 ID 的真实争抢采集专门样本，并固定方案后做独立验证。当前候选只代表反复使用的八文件校准表现，不保证官网同幅度提高。

## 复现与产物

训练入口为 `learn.py collect/train`，评分纠偏选择为 `fusion.py`；每个文件均检查数据、先验权重或源码 SHA-256。`replay.py` 只允许固定八文件，`--memory-guard .90` 打开独立记忆更新检查，`--blend-config` 使用验证选定的评分纠偏参数。CLI 需要既有 fit64/cal8 ZIP、点分数缓存、原始长期记忆检查点和同目标评分器。它们不包含在 Git。

```text
python experiments/continuation/replay.py --data FIT64_CAL8.zip --cache CACHE64 --prior MEMORY.pt --affinity AFFINITY.pt --reference WIDE/summary.json --method wide_shadow --checkpoint HEAD.pt --blend-config FUSION.json --memory-guard .90 --out runs/continuation-replay
```

神经网络检查点只含推理权重和来源信息，保存在本地 `runs/v2-continuation/training` 与云端独立目录。本地结果入口为 `runs/v2-continuation/index.html`；分数表为 CSV/JSON。原始点迹、查看器及检查点不上传 Git；聚合证据、源码、测试和本报告进入独立分支。冻结 v1 的九项文件和底层 v2 运行源码通过摘要检查。
