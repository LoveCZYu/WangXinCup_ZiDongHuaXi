重分配保留实际选出的点和原状态轨迹，对同圈输出 ID 做唯一性约束；已有边包括当时记录的活跃候选、退役候选及首次输出转接提议。它不是重新运行一套拥有理想历史的策略，也不是最优可达算法或纯排序器上限。放宽几何边的额外收益有限，支持优先研究既有身份竞争，不能保证学习器实现 83.57 的零碎度。

当前有 807 个额外 ID 片段，其中 313 个只命中一两点：58 个此前从未发布该 ID，255 个此前发布过该 ID，247 个 ID 曾输出别的真目标。新 ID 出生检查因而只能覆盖其中一部分；已有 ID 被短暂串用及记忆状态值得优先研究。

8739 个未命中点按当时内部状态分成：输出门限过滤 2152、匹配但尚未确认 1888、新内部航迹起批 4697、无记录候选 2。另有 1958 个位于该真目标前两次观测、2220 个点分数低于维持阈值，这两项与前述划分重叠。**新内部航迹不等于真正新目标**，也可能是旧目标失配后的重复起批。

在固定现有命中点和首次输出时机的条件下，理想身份加去已知杂点仍只有本地 93.32，说明点选择、漏点和起批也需要研究。这不是整套架构上限，更不是官网上限，因为改关联后可能改变后续状态和选点。

## 下一轮应回答的问题

本阶段到此停止修改接续阈值，不围绕新 16 文件逐个修规则。后续把它们用于事先约定的少数成熟比较，并明确其已暴露身份。

下一轮假设：已有 ID 的真实争抢样本中，联合比较候选身份和“本圈不匹配”能减少短暂串用；收益应体现为额外 ID、混轨和连续性共同改善，而不仅是分类 AUC 上升。

1. 从原 fit64 运行中的真实争抢采样，保留冲突中的全部合格 ID、当前选中边、未匹配项和记忆可靠性。先审计难例中的正确边覆盖率、误拒绝和误接受分布。
2. 与旧 `joint_matching` 失败实验区分：旧方案最多三条已确认轨，独立修改局部分配；新对照需在同一竞争单元中比较活跃／暂失配身份及拒绝项，使用真实运行历史。不能只换名重复旧实验。
3. 先在拟合池内部按场景拆分训练／验证，比较独立二元判别与竞争归一化、拒绝监督。训练步数先由内部身份判别证据决定，再决定是否接入整场；不直接靠增加步数赌涨分。
4. 接入时先固定点分数、输出门和既有起批行为，单独测身份竞争干预。使用旧八文件做诊断；成熟后才做一次预注册新工作验证回归。正式 29 文件继续封存。
5. 若覆盖不足，转向运动预测／不确定性；若判别改善不能转化整场收益，检查拒绝校准和状态传播；若仍无稳定收益，不堆新阈值，给替代关联结构独立对照。

这是一项待执行的结构性实验，**本轮尚未训练或接入新联合模型**。下一轮运行前另存预算、主判据与失败停止条件，不用本次诊断分数当承诺。
