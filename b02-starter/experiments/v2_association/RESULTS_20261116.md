# v2 首轮结果：有效增量，尚非官网新版本

当前官网保底仍是冻结 v1 的 **75.24**。本轮没有上传官网，没有修改 v1 的算法、点权重、主配置或两个提交 ZIP。
新增候选通过了冻结后完整 30 文件开发回归；以下为同条件的本地估算，不能推断官网新分数。

预定种子总分增加 1.8417；连续子分增加 6.5819；变号约减少 24.8%、已知杂点约减少 5.4%。
点命中基本持平。及时性下降约 0.254 子分，逐航迹平均命中率也略降，不能概括成所有指标都提高。
混合 ID 内少数身份点明显减少，但仍有 2013 个输出 ID 接过多个真值目标，身份问题远未解决。

两个种子都通过事先登记的可行性条件：点命中最多下降 0.3 个百分点、杂点最多增加 5%、连续子分不降、
变号至少减少 5%、总分至少增加 0.25。较严格的阶段目标“连续 +3、变号 -25%”尚未全部达到，
不把约 25% 四舍五入当作严格过线，也不表示最初大幅提分目标已经完成。

校准阶段先完整验证八文件，v1 为 80.4095，两个候选分别 82.3127／82.4613。
种子 20261116 在开发验证前已指定为输出候选，不从开发结果挑种子。
两种子均训练至 8000 步，按事先固定的校准行损失规则选择了 1000 步检查点，再独立检验完整回放。
继续训练并非自动更好；本轮更多步数出现了拟合损失下降、校准损失回升。

## 做对了什么，放弃了什么

先完成四组状态／拒配规则对照，三个改动均不胜过 v1，全部保留失败记录。
直接联合学习真实边与拒配，校准行准确率达到约 95%，实际回放却损伤起批、连续性，未采用。
纯几何短历史排序、重复航迹所有者标签也未产生有效提升。

有效候选采用 **局部群体关系特征＋条件配对 MLP**：从当前高可信点的邻接图计算相对位置、幅度／SNR 中心差和相对秩，
再与过去航迹的群体关系比较。输入不含真值、数值 ID、文件名、输入行序或绝对时间。
它学习多候选之间的配对差异，保留 v1 的点模型、出生、确认、门控、拒配和输出门限。
这不是直接复现视觉 MOTIP，也不是只换一个更大的点分类器。

该分支有 60 维历史特征、50 维边特征、11202 个关联头参数；与冻结点模型共用后总参数量 20355。
推理关联权重为 51341 字节。训练使用 RTX3090，每种子 8000 步约 25 秒；主要耗时是数据准备和完整时序回放。
实例租用时间仍包括预处理与回放，不能用 GPU 计算秒数代替实际计费时间。

## 交付与复现

研究分支 `b02-v2-association`，主提交入口保持 v1。已有点模型环境中，在 `b02-starter` 目录运行：

```bash
python experiments/v2_association/candidate.py --profile profiles/v2-association-candidate.json --data YOUR_DATA.zip --scene train_015 --out runs/v2-preview --device cpu
python -m b02 visualize YOUR_DATA.zip --run runs/v2-preview --scene train_015 --out runs/v2-preview/train_015.html
```

第二条若需查 CLI 可使用 `python -m b02 visualize --help`；只生成明确指定场景，不批量读取封存文件。
便携加载器检查源文件、点主配置、权重及训练元数据哈希。模型权重共享，点历史、航迹和 ID 全部按数据包状态隔离。
本机完整 032 回放的非耗时统计，包括逐目标输出 ID 计数，与云端候选逐项一致。
本机该场景 P95 218.36 ms、最大 375.98 ms，仅为回放测量，尚未通过官方收发链路的完整时限与资源验收。
35 项测试通过。导出权重在云端 PyTorch 2.2 中与训练检查点逐张量相等，24 圈前缀输出一致；
完整 032 的本机复现使用 PyTorch 2.9 CPU。未因导出而重新训练或修改任何张量。

本机总入口 `runs/v2-training/index.html`，含校准 032、开发 015 的新旧二维查看器以及不同范围分开的结果表。
`comparison.csv/json` 和各版本的 `summary.json`、`scorecard.json`、`results.csv` 均保留。
原始点迹、完整训练检查点和查看器不放 Git；源代码、51 KB 推理权重、配套配置与本报告可共享。

开发采用四个互不重叠的场景分片，合并时验证全部 30 文件恰好覆盖一次；与已完成串行场景的逐目标统计完全一致。
模型、参数、策略在开发开始前固定，没有根据开发结果重新训练或调参。独立保留的 **29 文件完全未使用**。
