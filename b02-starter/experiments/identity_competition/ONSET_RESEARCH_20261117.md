本轮已完成：原拟合数据上的换号复现、最小化、单变量检查和四格整场对照。组合有小幅收益，但未达预定推进门槛，停止扩大实验。不重新使用新增 16 文件，不读取正式封存 29 文件。冻结提交版及原关联权重保持原样。完整聚合证据见 [column-results-20261117.json](column-results-20261117.json)。

## 可重复的实际错误

`train_093` 第 47 圈的目标点 10119，此前连续十次由 ID 5274 输出，本圈却输出为 5268。原状态保存后两次独立重放，完整输出相同。旧 ID 当圈仍有这个点的候选边。

将 226 条活跃轨迹、258 个输入点缩减为两条原始历史轨迹和一个原始点，换号仍能复现；移除剩余非目标输入点的逐点不可再减检查通过。保留的是原有模型与轨迹历史，不是人工合成数据。第二个原始案例在第 78 圈，目标点 17104 从 5268 换成 5274。

秒级反馈入口为 `repro.py FIXTURE.pkl`，原方案稳定返回 RED（退出码 1）；`--mode identity_volume` 检查修正。程序先核验私有案例摘要、原始完整输出与重复确定性，再运行干预。案例包含真实输入与状态，只存于忽略 Git 的 `runs` 和云端研究目录；pickle 入口仅用于本工具自行生成的可信文件，不能加载第三方文件。

## 四项假设及反证

| 假设 | 检查 | 本轮证据 |
| --- | --- | --- |
| 两个 ID 早已重复跟踪同一目标 | 查之前八个关联点及可信记忆的真实身份 | 第 47 圈之前，5274 的短历史八点均为 114、可信记忆七点均为 114；5268 相应均为 112。此例不支持重复同目标解释 |

| 不匹配项的差异导致争抢 | 查有效 dummy、实际 null 输出及训练掩码 | 两行有效 dummy 都为 1.15；当前权重的 null 最后层权重、偏置绝对值和均为 0。该案例不是两行 dummy 差异造成，但全局拒绝能力仍未训练 |
| 状态预测和失配后的门宽影响争抢 | 只改单条旧轨迹记忆拟合的位置／速度，再检查同时作用于所有竞争者 | 只改正确旧 ID 可修第 47 圈，却不修第 78 圈；对所有竞争者应用固定记忆直线代价也没有修好第 47 圈，不能凭单轨辅助结果直接推广 |

上述假设在单变量试验前列出。后续宽门体积修正是发现代价归一化后的追加对照，并非事先独立预测；整场检验前另存协议，防止把案例上的针对性设计当成未见验证。

## 已确认的训练／推理覆盖限制

主关联器的训练会筛掉“不匹配为目标”的行，以及真实候选数不大于一的行，随后将 null 从有效 loss 掩码排除。当前权重元数据记录：总候选行 336908、已知行 330855、进入排序训练的行 41306，只占全部记录约 12.26%。这不是说 87.74% 都是有用样本或应等权训练，而是当前优化目标明确只覆盖其中一类决策。

推理 `rank_only` 对每行将实边模型分数减该行最小值，只有一个候选时直接归零，dummy 修正也归零。因此它能回答“本轨迹的多个点选哪个”，不能直接学习“只有一个候选也应该拒绝”，并丢弃了跨轨迹比较需要的行间绝对偏置。若仅增加原训练步数，这些被排除的决策仍没有进入优化目标。

直接恢复该排序网络的原始绝对分数，能修第 47 圈而不能修第 78 圈。该网络按行训练，跨行偏置没有经过绝对身份校准，故没有将它作为整场推广候选。同身份判别器是另一个已存在的二元模型；它的分数也未证明在所有真实争抢中可靠，仍需整场副作用检查。

## 宽门竞争折扣与追加对照

当前距离项形如 `距离平方 / radius²`，失配后 radius 从 1 增到最多 1.6。扩大门有利于保留不确定候选，但同时降低归一化距离代价，可能使暂失配的竞争 ID 获得额外优势。

第 47 圈中正确 ID 的 age 为 1、基础代价约 0.04553；错误 ID 的 age 为 2、基础代价约 0.03044。加入固定门体积惩罚后此例保持旧身份，第 78 圈两者 age 都为 1，单独体积惩罚不起作用；跨 ID 身份惩罚补充了另一个案例。

门宽不是已标定的协方差，不能把这一惩罚宣称为严格正确的高斯概率模型。本轮只将其作为有明确机制的固定干预：三维门体积对应 `3*log(radius)`，在同一点的竞争列内减去最小值，经现有 solver 的 0.25 比例进入代价。这个系数没有按案例搜索。

## 固定四格实验

只干预至少两条已发布三次的 ID 对同一个强点的争抢；点起始门槛、候选边、dummy、起批与退出规则不变。每列最佳证据的额外代价为零，其他边只加非负惩罚。但全局一对一分配存在耦合，这**不保证整场输出点或命中率不变**。

四格为：原方案、仅列内同身份代价、仅门体积代价、两者组合。原方案在每圈同时运行未包装候选，要求全部输出逐项一致。主比较固定为组合减原方案，单项只解释机制，不根据事后均值另挑赢家。

先跑同一批原拟合池八文件，只有达到预定保护条件、零碎度至少加 1、本地总分至少加 0.2，才允许原样跑旧八文件校准。校准要求零碎度至少加 2、本地总分至少加 0.5，且命中、连续性、及时性、杂点、混轨都过保护条件。预算为四个单线程 CPU worker，各最多 1800 秒；没有训练、没有阈值搜索。协议见 `column-protocol.json`。

## 进一步提高的结构方向

如果小范围代价修正不足，训练数据和目标要跟着实际决策改变，而不只是扩大步数：

1. 保留实际运行产生的单候选、无正确候选、强点串用与暂失配争抢；未知 −1 不能随意当负例。
2. 同时监督“本 ID 的正确点或不匹配”和“这个点的正确历史身份或暂不分配”，使跨 ID 比较与拒绝进入目标。保留一对一约束，不能每条 ID 各自抢最高分点。
3. 训练／内部验证按场景分开，先证明身份判别和拒绝可靠，再接完整状态更新。检查错误接受是否写入长期记忆，并单独比较记忆隔离效果。
4. 对不在候选内的正确身份，先区分运动门、阶段优先级、裁剪与失配退出；评分网络不能恢复不存在的边。需要扩大候选时与拒绝能力一起验证，不能只扩大所有门。

这些是根据本轮证据提出的下一轮结构实验，尚未完成新模型训练，也不承诺能达到官网某个分数。新增 16 文件已经是暴露的工作验证，正式 29 文件继续保留。
