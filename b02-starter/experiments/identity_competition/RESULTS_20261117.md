# 身份竞争前置检查：拒绝与候选缺失

2026-11-17，接续 [冻结验证阶段](../robust_validation/RESULTS_20261117.md)。这是一项新增的拟合池只读诊断，**没有新训练、没有新模型或新分数**，不是另一轮未见验证，也不触碰正式 29 文件。

## 运行前范围

按固定盐的场景名哈希，在已有 fit64 内选取八文件：train_093、177、148、090、106、198、017、094。运行前固定源码、数据和协议摘要，四个单线程 CPU worker，每个最长 900 秒。实际各 worker 完成约 92–131 秒，退出码为 0，无本轮残留进程，没有使用 GPU 训练。详细运行前约束见 [preflight-protocol.json](preflight-protocol.json)，完整计数见 [RESULTS_20261117.json](RESULTS_20261117.json)。

只读观察器不把真实标签写入 tracker。每圈使用以前已发布的已知标签建立两个诊断参考；当前标签不能给本圈自己的身份锚定。已有 ID 行要求至少三次目标命中，且该真目标在历史已知输出中占比至少 80%，已知杂点计入分母、−1 不计。历史主 ID 则按每个真目标以前已发布的命中次数最多者确定，至少三次；这两个参考不可混为一谈。

## 实际关联中的排序和拒绝

有历史身份锚的记录行共 155616 次，其中本身份真目标在输入中存在 143793 次，有正确记录候选 139408 次；条件覆盖率约 96.95%。这是有纯净历史锚的条件统计，不是全部 ID 或未见场景的召回保证。

| 内部关联结果 | 有本身份正确候选 | 没有本身份正确候选 |
| --- | ---: | ---: |
| 匹配正确身份 | 137544 | 0 |
| 匹配其他真目标 | 372 | 1739 |
| 匹配已知杂点 | 176 | 1151 |
| 匹配未知标签点 | 17 | 628 |
| 没有匹配 | 1299 | 12690 |

2111 次错接其他真目标中，1739 次（82.38%）没有本身份正确候选。对这些行，只把已存在的正确边排到第一位是不够的；需要拒绝项监督，同时审核正确候选为何缺失。不能只将未选中的历史 ID 强制接回。

2111 次错接中，1864 次（88.30%）的点分数达到当前起始门槛。**点是目标的置信度，不能替代点属于某个 ID 的置信度。** 这与仅过滤弱杂点不同，继续提高点阈值不一定能阻止强目标间的身份串用。

在这些已有身份锚的记录行里，真实进入可信长期记忆的更新包含 919 次其他真目标、83 次已知杂点、124933 次本身份真目标。425 次未知标签更新单列，不据此判错。它提示高置信错误身份仍能污染记忆，但不是完整因果试验：没有做“禁止这些更新后重跑”的对照，不能把每次污染直接换算成丢失或扣分。

内部关联不同于最终输出：很多已知杂点或低分点会被输出门过滤，关联本身仍可能更新物理状态。这里只描述计数，不把 1327 次已知杂点内部关联误写成最终虚警数。

## 历史主 ID 参考的逐点缺口

146245 个点有至少三次历史命中可作为主 ID 参考，其中 123080 个仍输出给该 ID，23165 个没有：

| 未交给历史主 ID 时的条件 | 点数 | 占上述缺口 |
| --- | ---: | ---: |
| 历史主 ID 有该点的记录边 | 3365 | 14.53% |
| 只到几何候选，未进记录 top-k 边 | 158 | 0.68% |
| 调用前仍在活跃／退役集合，但没有记录边 | 6566 | 28.34% |
| 调用前已不在这些集合 | 13076 | 56.45% |

有 17718 个缺口点输出给了别的 ID，5447 个没输出。没有记录边也可能来自阶段优先级、占用、保留条件、门限或候选裁剪，不能直接全部归因于运动门。

**这里是点数，不是额外 ID 出生次数或初始丢失次数。** 一次早期身份丢失会在后面的很多圈累计为“旧 ID 在集合外”；历史主 ID 在足够多新命中后还可能改变。因此不能把 56.45% 解释为“延长保留可恢复一半错误”，也不能用这一统计推算真实可达分数。

## 对下一轮的约束

本次已有足够错接例子，不需要为凑样本立刻扩大验证数据。此前“候选里的旧 ID 选择”仍有研究价值，但应与拒绝错误边结合，且不能忽略丢失状态的传播。

下一项应在原拟合池追溯**身份首次丢失的开端**，区分：有正确边但被其他 ID 抢走、正确身份点未入候选、旧 ID 被强目标／杂点牵走、真实观测空缺后自然过期。将开端事件与后续累计缺口分开，避免从点加权统计反推出错误干预。

之后才预注册真实竞争／拒绝模型的训练对照：使用实际运行历史中的困难边及不匹配项，保持点模型和输出门冻结；先在拟合池内部按场景检查身份判别，再考察整场副作用。和旧三轨局部重排实验的差别必须明确，而不能仅将已有方案换名重做。当前阶段没有启动这个新模型训练，仍不升级版本。
