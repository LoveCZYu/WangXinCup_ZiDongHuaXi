# 固定组合的内部校准对照

航迹证据优先和低分速度更新组合后，本地总分与连续跟踪改善，部分抵消了单独速度更新造成的杂点增加。组合值得保留为实验候选，但尚未满足预先固定的命中率不降、杂点不增条件，当前对照和默认算法继续保留。

## 范围与复现

沿用 8 个内部校准文件、种子 20261112／20261113、8000 步权重、输出阈值 0.50／0.05、历史三圈及关联点分数权重 0.50。证据优先仍使用最多六次高分历史和最大 0.15 实边附加代价，速度增量仍乘以 `min(1, 点分数 / 0.50)`。仅将上一轮两个改动一起启用，未改变常数或增加训练。

本轮新增对照和组合的 32 次场景回放。对照组全部逐场景非耗时统计同时复现原阈值实验和上一轮单项实验。复用上一轮两项单独改动的 32 次场景结果，形成四组固定对照。运行目录记录旧报告及 manifest 的 SHA-256，所有组使用相同数据、检查点和评分口径。

组合接入前，通过三种旧实现各 80 帧的源码兼容性检查，输出、航迹状态、证据计数和输出门历史逐项相等。合成检查同时确认组合确实启用了两项改动。真值只用于回放计分和诊断，不进入真实匹配或状态更新。

## 两项改动是否互补

如果把两项单独的分数增益直接相加，预期为 +0.321784；实际组合为 +0.463390，差额约 +0.141606。连续子分也额外增加约 0.339544。由此可见，关联竞争与速度状态更新存在交互，收益不能简单相加。

杂点的组合变化为 +352，比两项单独变化相加的 +576.5 少 224.5，但没有完全抵消速度更新带来的杂点增加。该结果支持继续保留这条组合路线，下一步优先小范围校准输出门限，检查能否在保留连续跟踪收益的同时把杂点压回对照水平；之后冻结候选再验证完整开发集。

## 复现

在原 CUDA 环境中运行，`--prior-run` 指向上一轮单项实验目录。

```bash
python experiments/association/check_interventions.py
timeout --signal=TERM --kill-after=10s 600s python experiments/association/compare_interventions.py \
  --project . --data /path/to/point-expanded-data.zip \
  --steps-run runs/b02-association-steps01 --reference runs/b02-association-threshold02 \
  --prior-run runs/b02-association-intervention01 --variants control combined \
  --out runs/association-combination-new --seconds 540
```

本轮云端用时 174.67 秒，无新增训练，结束后无 GPU 计算进程。只读取内部校准文件，未回放开发集或封存测试集。默认不传 `--variants` 时仍运行原三组单项对照。历史单项源码保存在提交 `71b013b` 及本地冻结源码包中。
