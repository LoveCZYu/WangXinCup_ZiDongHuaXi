# 航迹竞争与低分速度更新的单变量对照

两项改动都产生小幅本地分数收益，但分别牺牲命中率或增加杂点，没有通过预先固定的采用条件。保留原 8000 步、0.50／0.05 版本作为当前对照。未替换默认算法，未追加训练，未回放开发集或封存测试集。

## 实验范围与改动

固定原 8 个内部校准文件、两个既定种子、8000 步权重、输出阈值 0.50／0.05、历史三圈、关联点分数权重 0.50。三组每个场景共享一次不依赖标签的特征及点分数计算，各自维护独立的航迹和输出门状态。共完成 48 次完整场景回放。

- 对照组 `control` 使用当前关联、速度及输出规则，全部 16 个场景与原 GPU 回放的非耗时统计逐项一致。
- `evidence_priority` 测试航迹证据优先。在原实边代价上加 `0.15 × (1 − min(历史高分命中次数, 6) / 6)`，历史高分定义为点分数至少 0.50。虚拟未匹配代价仍为 1.15，候选门、每轨候选数量及其他更新不变。它测试不同历史证据的并存航迹竞争，不是依赖航迹历史的身份匹配模型。
- `confidence_velocity` 只测试速度更新。将原速度增量乘以 `min(1, 当前点分数 / 0.50)`。位置、命中计数、候选创建、失配删除和最终输出规则不变。它没有测试低分匹配对位置等其他内部状态的全部影响。

参数在回放前固定，没有扫参，也没有组合两项改动。采用条件要求两个种子各自的命中率不低于当前版本、杂点不高于当前版本，且平均连续子分和平均总分都提高。

航迹证据优先相对当前版本，杂点减少 4.35%，变号减少 4.23%，连续子分增加 0.164，总分增加 0.093，但点命中率下降 0.0518 个百分点，及时性子分从 85.541 降至 85.125。两个种子的命中率均下降，因此未通过采用条件。

减弱低分速度更新相对当前版本，点命中率提高 0.0578 个百分点，连续子分增加 0.510，总分增加 0.229，变号减少 1.95%，但杂点增加 10.30%。两个种子的杂点均增加，因此也未通过采用条件。

## 身份混淆与具体案例

按输出 ID 所接真值点最多的真值作为其主要身份，统计其他真值的点数作为混入点。当前版本平均为 17320.5，航迹证据优先为 17403，减弱低分速度更新为 17082。航迹证据优先虽减少了输出 ID 和变号，混入点没有随之减少。速度更新方案在第一个种子减少 478 个混入点，第二个种子增加 1 个，仍不能认为身份混淆已稳定解决。

在预先选定的 `train_032` 案例中，真值 6、7 的第 17/18 圈输出如下。只比较同一方案内部的 ID 连续性，不比较不同方案 ID 数字的大小。

| 方案 | 第 17 圈：真值 6／7 | 第 18 圈：真值 6／7 |
| --- | --- | --- |
| 当前对照 | 1567／2359 | 2359／1567 |
| 航迹证据优先 | 1595／2399 | 2399／1595 |
| 减弱低分速度更新 | 1547／1548 | 1547／1548 |

速度更新方案消除了这个局部案例中的互换。全量变号仍只减少约 1.95%，两项实验均未显著突破当前分数平台。该结果支持继续研究状态更新与关联兼容性，但不能把局部案例当作整体问题已经解决。
