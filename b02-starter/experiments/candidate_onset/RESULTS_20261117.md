# 首次断轨与旧 ID 补救实验

12 个拟合池场景的审计表明，正确点被主运动门排除是首次可见失败中最常见的一类。训练 4 场景为 950／2091，内部开发 8 场景为 1639／3742。在这两组运动门失败中，866／950 和 1531／1639 条不符合原关联样本的采集条件。计数单位是一次身份失配事件，直到同一 ID 恢复才结束。审计参考只依据此前已发布的输出，真值仅用于事后归因。

首次失败和新增输出 ID 的来源有差异。在训练 4 场景中，950 次运动门失败有 772 次最终由原 ID 恢复，期间没有其他 ID 接续。实际出现其他输出 ID 的 646 次事件中，458 次正确点本来就在候选里，150 次正确点被运动门排除。补候选和处理候选之间的竞争分别覆盖不同类型的问题。

`train_098` 第 14 圈的正确点置信度为 0.998，原预测归一化残差 1.192，超过门限 1。此前的原始观测与可信记忆均对应同一真值身份。用此前可信观测拟合的位置替换上次状态位置，残差降至 0.376。保留实际轨迹历史后，病例可从 337 条轨迹和 285 个输入点缩减为一条轨迹和一个点。完整及最小病例均可重放，条件补救在两处均恢复原 ID。

用同样的条件直接覆盖状态，在训练 4 场景的总分从 83.89 降至 80.10。另一项仅用训练 4 场景的运动诊断采用真值关联的历史点，当前速度更新的门覆盖率为 98.12%，过去 16 点做直线外推为 88.32%。这项诊断评估预测覆盖，推理时没有真值关联可用。两项结果支持将可信拟合限定为备用候选来源。

备用候选只面向既有 ID 在确认阶段未匹配且原候选为空的情况，只使用高置信未占用点。增加身份确认和竞争边际后，训练 4 场景总分 83.89→84.35，零碎度提升 0.923，未达到事先约定的 +1.0。两项独立对照的失败记录保留在结果目录。

随后进行固定因子对照，在身份竞争与备用候选各开或关的四组中比较组合。评分使用本地估分，工作 16 已用于此前实验。

| 场景 | 总分 | 零碎度 | 连续跟踪 | 点命中率 | 混轨少数点 |
|---|---:|---:|---:|---:|---:|
| 训练 4 | 83.89→84.57 | 69.31→71.18 | 85.88→87.08 | 93.60%→93.90% | 1175→961 |
| 开发 8 | 83.99→84.74 | 68.85→70.89 | 85.80→87.17 | 93.89%→94.22% | 4264→2880 |
| 工作 16 | 84.31→84.98 | 67.64→69.55 | 86.53→87.59 | 94.29%→94.55% | 5264→5417 |

工作 16 每个场景的本地总分均上升。配对场景总分增量均值为 +0.695，重采样区间为 [+0.476, +0.921]。两处集中增量是 `train_010` 的 +459 和 `train_072` 的 +198，其余场景净减 504。冻结组合未通过预先约定的混轨条件，保留研究候选身份。正式封存集仍承担独立验证用途。

## 工作 16 混轨定位

在相同工作场景上补齐两个单项对照，原方案和组合沿用冻结结果。两个重点反例的原方案和组合重新回放后，各项轨迹统计与先前结果完全相同。

| 方案 | 本地总分 | 混轨少数点 | train_010 混轨点 | train_072 混轨点 |
|---|---:|---:|---:|---:|
| 原方案 | 84.3076 | 5264 | 505 | 354 |
| 仅身份竞争 | 84.3948 | 5379 | 966 | 471 |
| 仅补救 | 84.8996 | 5337 | 505 | 442 |
| 组合 | 84.9786 | 5417 | 964 | 552 |

在 `train_010` 第 237 圈，输出 ID 8577 此前有 164 个点属于真值 31。真值 32 的点 53245 同时被 ID 8577 和 9957 竞争。两条边的身份分分别是 −0.515 和 −1.815。相对身份分把 9957 的匹配代价从 0.056 提高到 0.381，超过 8577 的 0.082。同一历史状态下，身份竞争打开即发生错接，单开补救时仍分给 9957。

在 `train_072` 第 254 圈，ID 24683 此前的 95 个目标点都属于真值 75。用组合方案生成历史状态并固定这段历史后，四种开关组合都把真值 40 的点分给该 ID，获选边的身份分为 3.525。整场总量上的差异无法归因于这一次分配。

根据 `train_010` 的反例，固定试验了一个身份分下限。只有同一点最强候选的身份 logit 达到 0 才施加原列惩罚，其余设置沿用原组合。该策略在第 237 圈把点还给 ID 9957，在第 254 圈的另一个反例上没有改变分配。完整工作 16 的总分 84.9815，零碎度 69.5754，连续子分 87.5788，点命中率 94.5645%。相对原组合，混轨总数从 5417 升到 5547。虽然 `train_010` 少了 107 点，`train_006` 和 `train_064` 分别多出 169 和 137 点。该下限源自已看到的反例，工作 16 的复跑属于探索性对照。

下一步可在已开发的轨迹中抽取两类有标签的困难负例。第一类是高身份分的错误匹配。第二类是一次错接后，后续几圈持续沿用错误身份。按错接事件采样，避免把同一段持续污染重复计为多个独立错误。分别验证当圈身份排序和后续状态更新的影响。

## 查看与复现

工作区内可通过以下入口生成本地分数表和回放。点模型和其余已冻结权重可使用本地研究包。

```powershell
python -m experiments.candidate_onset_report runs/candidate-onset
python -m experiments.candidate_onset_runtime PATH_TO_TRAINING_ZIP --scene train_098 --out runs/replay-098
python -m b02 visualize PATH_TO_TRAINING_ZIP --run runs/replay-098 --scene train_098 --out runs/replay-098.html
```

`train_098` 的研究入口从点迹重新计算分数，719 圈逐圈输出与云端点分数缓存回放完全一致。冻结实验协议、汇总报告和病例数值一并保存。

仓库中的汇总文件可直接生成分数表，无需点迹与权重。

```powershell
python -m experiments.candidate_onset_report experiments/candidate_onset/results
```
